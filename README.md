# GEX Levels（NAS100 / XAUUSD / BTCUSD）

TradingView の Pine はオプションのデータを取得できません。そのため、次の2段構成で動かします。

1. **`gex_levels.py`** が無料データから GEX を計算し、貼り付け用の1行の文字列を書き出します。
2. **`GEX_Levels.pine`** の設定「GEXデータ」にその文字列を貼ると、チャートの銘柄に合うレベルを CFD 価格に換算して描画します。

| チャート | 元データ | 取得先 | 乗数 |
|---|---|---|---|
| NAS100 | QQQ（`--nas-source ndx` で NDX） | CBOE 遅延チェーン | 100 |
| XAUUSD | GLD | CBOE 遅延チェーン | 100 |
| BTCUSD | BTC オプション | Deribit 公開API | 1（1枚=1BTC） |

APIキーも追加ライブラリも要りません（Python 3.9 以上の標準ライブラリだけで動きます）。

## 使い方

```bash
cd ~/インジケーター開発/GEX
python3 gex_levels.py --copy        # 3銘柄を更新し、貼り付け文字列をクリップボードへ
```

1. TradingView で `GEX_Levels.pine` を新しいインジケーターとして保存し、チャートに追加します。
2. 設定 →「GEXデータ」に、クリップボードの内容（または `output/tv_input.txt` の中身）を貼ります。
   - 3銘柄分が1行にまとまっています。NAS100・XAUUSD・BTCUSD のどのチャートでも同じ文字列を貼れば、銘柄は自動で判定されます。
3. 更新したら、同じ欄に貼り直します。

**更新の目安:** QQQ・GLD は米国市場の寄り前に1回貼れば十分です。建玉は日次でしか更新されません。BTC は24時間動くので、必要なときに `python3 gex_levels.py BTCUSD --copy` で更新してください。

## クラウドでの自動更新（PC不要）

GitHub Actions（`.github/workflows/gex.yml`）が毎時7分（UTC）に計算します。結果はスマホ用ページに出ます。

- **ページ:** https://aoimiku.github.io/gex-levels/
  - 3銘柄のレベル一覧と、ストライク別のGEXを表示します。
  - 「TradingView 用データをコピー」ボタンで、貼り付け用の文字列をコピーできます。
- **使い方:** ページを開いてコピーし、TradingView（スマホアプリでも可）のインジケーター設定「GEXデータ」に貼ります。
- **クラウドの結果の保存先:** `data/`（`output/`・`history/` と同じ構成）と `docs/index.html` です。手元で実行した結果（`output/`・`history/`）は、リポジトリには入れていません。
- **生データの保存方法（クラウドのみ）:** リポジトリが大きくなりすぎないよう、次のように間引いています。
  - 建玉があり、現値±25%以内のオプションだけを残します（`--raw filtered`）。
  - 保存は最短3時間おきです（`--raw-every 3`）。
  - レベルの履歴（`data/history/levels.csv`）は毎回保存します。
- **手動で実行したいとき:** GitHub の Actions タブ →「GEX update」→「Run workflow」。
- **注意:** GitHub の定時実行は、混雑で十数分遅れることがあります。また、長期間リポジトリに動きがないと止まることがあります。止まった場合は GitHub からメールが届くので、Actions タブで再度有効にしてください。

## 表示されるもの

- **ガンマフリップ（橙）:** 現物価格を仮に上下させて合計 GEX を計算し直し、0 を跨ぐ価格です。現値に最も近いものを採用します。
- **コールウォール（緑）:** コール GEX が最大のストライクです。
- **プットウォール（赤）:** プット GEX（絶対値）が最大のストライクです。
- **ピン（紫）:** 純 GEX の絶対値が最大のストライクです。
- **線の種類:** 実線は全満期、破線は直近満期（QQQ なら当日の 0DTE）です。同じ価格に重なったレベルは1本にまとめます（例:「コールW/ピン」）。
- **右側の棒:** ストライク別の純 GEX（全満期、上位40本）です。緑が正、赤が負です。
- **背景:** データ時刻以降、価格がフリップより上なら緑（正ガンマ。値動きが抑えられやすい）、下なら赤（負ガンマ。値動きが拡大しやすい）です。
- **テーブル:** データ時刻と経過時間（30時間を超えると「⚠古い」）、換算比率、レジーム、各レベルを表示します。
- **アラート:** フリップの交差、コールウォールの上抜け、プットウォールの下抜けを設定できます。

### CFD への換算

既定は「スナップショット比率」です。比率は次の式で求めます。

> 比率 = 元データの価格がついた時刻のチャート終値 ÷ 元データの現値

XAUUSD÷GLD、NAS100÷QQQ を、貼り直すたびに取り直す仕組みです。CBOE は遅延データなので、原資産に価格がついた実際の時刻（引け後なら 16:00 ET）に合わせます。BTC の比率はほぼ 1.0 です。

- 5分足〜1時間足なら正確です。日足では、その時刻を含む日足の終値を使うため、少しずれます。
- チャートの履歴がその時刻まで届かないときは、「手動比率」に切り替わります。テーブルに注記が出ます。

## 計算方法

- **GEX（1%変動あたり）** = ガンマ × 建玉 × 乗数 × 原資産価格² × 0.01 です。コールは加算、プットは減算します（ディーラーはコール買い・プット売りと仮定）。
- **除外する行:** 満期済み、IV が 0 以下（古い気配）、建玉 0 の行です。
- **ストライクの範囲:** 現値から QQQ ±10%、GLD ±12%、BTC ±15% です。`TARGETS` で変更できます。
- **ガンマ:** CBOE の計算済みの値は使わず、IV から Black-Scholes で計算し直しています。理由は次の2つです。
  1. 2026-10-01 に照合したところ、CBOE の gamma 列は終値 742.8 ではなく、約 740.6 時点の価格で計算された古い値でした。その価格を仮定すると、CBOE の値とほぼ一致します。
  2. 値は小数4桁に丸められており、NDX では 0.0001 程度しか残りません。
- **純 GEX の感度:** 純 GEX はコールとプットの差なので、原資産価格や残存期間の少しの違いで大きく変わります。例えば、上の古いガンマで計算すると QQQ は +1,671M$、現値で計算すると +2,897M$ でした。
- **残存期間の基準:** 原資産の価格時刻から測ります。引け後に実行しても、引け時点の価格と残存期間の組で計算されるので、結果がぶれません。
- **Deribit:** 満期ごとの先物価格（`underlying_price`）に対して Black-76（r=0）で計算します。フリップを探すときは、各先物を現値と同じ率で動かします。

## 保存されるファイル

| パス | 中身 |
|---|---|
| `output/tv_input.txt` | Pine に貼る文字列（3銘柄分） |
| `output/latest_<銘柄>.txt` | 銘柄別の最新ブロック。銘柄ごとに別の頻度で実行しても、連結し直されます。 |
| `history/levels.csv` | 取得のたびのレベル履歴 |
| `history/raw/<QQQ・GLD・BTC>/<日付>.csv.gz` | 全オプションの生スナップショット（建玉・IV・気配）。**将来のバックテストに使える唯一の履歴**です。 |

CBOE は、引け後や週末のように原資産の価格時刻が前回と同じなら保存しません。

## 手元のMacでの定期実行（任意・クラウドを使うなら不要）

`run_gex.sh` を毎時5分に実行する launchd の設定が、`com.aoi.gexlevels.plist` に入っています。履歴を溜めたい場合は、次のコマンドで登録してください。

```bash
cp ~/インジケーター開発/GEX/com.aoi.gexlevels.plist ~/Library/LaunchAgents/ && launchctl load ~/Library/LaunchAgents/com.aoi.gexlevels.plist
```

止めるときは次のコマンドです。

```bash
launchctl unload ~/Library/LaunchAgents/com.aoi.gexlevels.plist
```

ログは `output/run.log` に出ます。Mac がスリープ中の回は実行されません。

## 注意点

- **前提の違い:** 「ディーラーはコール買い・プット売り」という仮定は、株価指数向けです。BTC とゴールドでは精度が落ちるので、参考値として扱ってください。
- **GLD の取引時間:** GLD のオプションは米国時間しか動かないため、アジア・欧州時間の XAUUSD とは完全には連動しません。
- **NAS100 の元データ:** QQQ と NDX では、オプションの持ち手が違うためレベルも違います。2026-10-01 の例では、フリップは QQQ 換算で約 30,150、NDX で 29,510 でした。
- **検証:** 一度、無料で公開されている GEX のサンプルと比べて、レベルが大きくずれていないか確認してください。チャートのラベルに元のストライク（例 `[QQQ 760]`）が出るので、照合しやすくなっています。
